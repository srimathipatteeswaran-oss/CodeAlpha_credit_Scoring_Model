Credit Scoring Model using Machine Learning

Project Overview

This project predicts the credit risk of customers using Machine Learning techniques. It uses customer financial information to classify credit risk.

Dataset

German Credit Dataset (OpenML).

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

Machine Learning Algorithm

Random Forest Classifier.

Data Preprocessing

- Handling missing values
- One-Hot Encoding
- Feature Scaling
- Training and Testing Split

Model Evaluation

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

Project Output

The trained model predicts credit risk categories based on the input data.
